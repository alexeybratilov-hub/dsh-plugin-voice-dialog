# Скриншоты

Здесь лежат скриншоты интерфейса. Пока в репозитории есть только фрагмент
композера (`docs/composer-buttons.png`), снятый с работающего приложения.

Чтобы добавить остальные, снимите экран в работающем DSH (Win+Shift+S) и
положите файлы сюда:

| Файл | Что снять |
|---|---|
| `panel.png` | Вкладка «Ассистент» целиком: личность, обратные настройки, голос, длина записи |
| `status.png` | Строка статуса там же: фаза, уровень микрофона, «Распознано», «Чтение: N/M» |
| `composer.png` | Композер: капибара и динамик рядом с кнопкой отправки |
| `mic-off.png` | Та же кнопка выключенной (перечёркнутая) для контраста |

После этого README ссылается на файлы — достаточно закоммитить.
