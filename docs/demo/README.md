# Демо

`demo.wav` — реальный звук из плагина, не макет: сигнал «дзынь-дон» (988 → 1319 Гц,
как в приложении), затем ответ ассистента, синтезированный тем же воркером Silero,
что читает ответы. Текст ответа специально содержит числа и английские слова.

## Расшифровка

> **Вы:** «Валера, что уже сделано в ассистенте?»
>
> *(сигнал)*
>
> **Ассистент:** Сделано многое. Активация по имени работает на своей модели: ноль
> ложных срабатываний на ста пятидесяти фразах. Распознавание занимает шестьдесят
> четыре миллисекунды, озвучка — сто двадцать. Читаю и русский, и английский:
> hello world, the server is down. Числа тоже читаю словами: в две тысячи двадцать
> шестом году.

Вопрос пользователя в записи не звучит: он идёт текстом, а демо показывает
именно то, что делает плагин — сигнал и чтение ответа.

## Как записано

```
POST /voice-dialog/tts  {"text":"…","voice":"baya"}
```

Ответ — WAV 48 кГц; к началу добавлен синтезированный сигнал, файл прорежен до
24 кГц моно для репозитория. Ничего не редактировалось вручную: тот же движок,
что работает в ассистенте.
