# Приватность

Плагин создан для полностью локальной работы.

## Что не покидает машину

- **Звук микрофона.** Куски речи уходят только в собственный хост-плагин по
  `http://127.0.0.1` — этот же процесс DSH. Никаких внешних сервисов.
- **Текст ответов.** Синтез идёт локальной моделью Silero на CPU.
- **Распознавание.** GigaAM работает через хост-сервис DSH (тоже локальная
  модель). Если он недоступен — локальный Whisper int8.
- **Личность и факты.** `~/.dsh/voice-assistant.json` читается локально
  плагином и подмешивается в системный промпт сессии.

## Сеть

Нужна один раз, при установке: скачать модели (`scripts/setup-models.ps1`,
`engine/tts/setup.ps1`) и пакеты Python в venv. После установки плагин работает
без интернета.

## Права и ограничения

- Микрофон запрашивается браузером через `getUserMedia`: разрешение выдаётся
  один раз на адрес DSH. Пока плагин выключен или микрофон отключён кнопкой,
  устройство не открывается.
- Хост-маршруты плагина отвечают только на loopback (проверка адреса запроса).
- Телеметрии, аналитики и «домашних звонков» нет.
- Журналы: DSH пишет свою сессию как обычно; плагин хранит только счётчики
  диагностики в памяти и строку `diag` в статусе.

## Ваши записи голоса

Кнопка «Запись голоса» во вкладке «Ассистент» сохраняет примеры в
`%LOCALAPPDATA%\kws\real\pos|neg` — только для дообучения детектора имени.
Файлы не покидают машину; папку можно удалить в любой момент.
