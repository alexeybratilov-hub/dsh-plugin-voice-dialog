# Как устроено

## Слои

```
┌─────────────────────────── клиент (браузер) ───────────────────────────┐
│ микрофон → кольцевой буфер 20 с → куски по 100 мс → POST /wake          │
│ имя найдено → запись команды → POST /transcribe → текст в композер      │
│ ответ → GET /reply → POST /tts по фразам → AudioContext (встык)         │
└─────────────────────────────────────────────────────────────────────────┘
                                    │ loopback HTTP
┌─────────────────────────── хост (DSH, Node) ───────────────────────────┐
│ /wake        KWS-модель (torch) + VAD, счёт 21 мс на кусок              │
│ /transcribe  GigaAM через хост-сервис DSH, иначе Whisper int8           │
│ /tts         Python-воркер Silero: SSML, цифры словами, транслит        │
│ /reply       последний ответ ассистента для озвучки                     │
│ /assistant   персона, обращение, поправки, факты                        │
└─────────────────────────────────────────────────────────────────────────┘
```

## Детектор имени

Своя свёрточная сеть на log-mel спектрограмме: 40 полос, окно 25 мс, шаг
10 мс, окно распознавания 1,5 с (151×40). Четыре свёрточных слоя, ~30 тыс.
параметров, вес 326 КБ. Считается 5,2 мс на окно в том же Python-воркере, что
синтезирует речь, поэтому отдельный процесс не нужен.

Обучение: синтетика Silero (5 голосов) + реальные записи пользователя, аугментация
шумом. Порог 0,85. На отложенной выборке 98 % попаданий и 0 ложных на речи без
имени.

## Распознавание

Основной путь — GigaAM через `speechToText` DSH: 64–92 мс на короткую фразу.
Если провайдер отвечает ошибкой (или пустым текстом — это не ошибка), плагин не
отключает его, а просто возвращает «речи нет». Whisper small int8 — запасной
путь для случаев, когда хост-сервис недоступен.

Короткие команды закрываются паузой 1,3 с, средние — 3,5 с, длинная диктовка —
не больше 5 с. Пауза засчитывается, только если и серверный VAD, и локальный
уровень согласны, что речь закончилась: тихий микрофон иначе обрывал фразу.

## Озвучка

Один голос для всего: Silero v5_6_ru. Английские куски текста переводим в
кириллицу по произношению через CMU Pronouncing Dictionary (ARPAbet → русские
буквы), поэтому тембр не меняется. Числа заменяются словами до синтеза:
русская модель цифры не произносит вовсе.

Ответ режется на фразы ≤180 символов. Буферы декодируются и планируются в одном
`AudioContext` встык — длинный ответ читается непрерывной дорожкой. Прерывание
(имя или текст в чат) останавливает источники, пауза — `suspend()` контекста.

## Производительность (i5-1135G7, без GPU)

| Операция | Время |
|---|---|
| кусок прослушивания (100 мс звука) | 21 мс |
| распознавание короткой команды | 64–92 мс |
| синтез русской фразы | 120–170 мс |
| синтез английской фразы (транслит) | 230–390 мс |
| загрузка воркера с моделями | ≈ 10 с (один раз) |

## Файлы

| Путь | Роль |
|---|---|
| `index.js` | хост: маршруты, движки, интеграция с DSH |
| `client.js` | клиент: микрофон, детекторы, проигрывание, панель |
| `lib/engine.js` | ASR: Whisper через sherpa-onnx, фолбэк CLI |
| `lib/wake-stream.js` | потоковый детектор имени по тексту |
| `lib/silero.js` | запуск Python-воркера, запросы synth/kws |
| `engine/tts/silero_worker.py` | сам воркер: Silero, цифры, транслит, KWS |
| `engine/tts/numerals_ru.py` | числа словами |
| `engine/tts/translit_en.py` | английский по произношению |
| `scripts/doctor.mjs` | проверка окружения |
| `scripts/setup-models.ps1` | загрузка моделей |
